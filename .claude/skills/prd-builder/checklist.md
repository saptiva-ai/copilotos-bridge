# Quality Checklist

Verificar antes de finalizar un mini-PRD:

## Agent-Readiness (CRITICAL)

- [ ] **Target Files table** con acciones CREATE/MODIFY y paths exactos
- [ ] **Example Input/Output** con JSON/data concretos
- [ ] **Validation Commands** que agentes pueden ejecutar
- [ ] **Sub-agent delegation** blocks con Agent, Task, Input, Output

## Alignment (Why)

- [ ] BRD use case citado explícitamente
- [ ] Conexión con North Star explicada
- [ ] Design principle mencionado

## Integration (How)

- [ ] Diagrama de componentes incluido
- [ ] Dependencies listadas con status
- [ ] Flujo input-processing-output claro

## Deliverables (What)

- [ ] Lista numerada de entregables con file paths
- [ ] Cada entregable tiene criterio de completitud
- [ ] Entregables mapeados a fases
