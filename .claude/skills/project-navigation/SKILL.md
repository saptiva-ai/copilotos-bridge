# Project Navigation

## Navigation Protocol

### Start here (doc index)
- Open `CLAUDE.md` and use the "Index" section to jump to the right docs.
- Quick locate: `rg -n "Index:" CLAUDE.md`.
- Repo map output lives in `.claude/docs/repo_map.md` (generated by `/repo-map`).

### Memory layers (lazy context)
- Root memory: `CLAUDE.md` (imports core docs).
- Path rules: `.claude/rules/*.md` (scoped guidance by path).
- Skills: `.claude/skills/*/SKILL.md` (on-demand workflows).
- Subtree memory: `apps/backend/CLAUDE.md`, `apps/web/CLAUDE.md`, `plugins/CLAUDE.md`.

### Where things live (high level)
- `apps/backend/src/` FastAPI API, routers, services (invoke `explore` skill).
- `apps/web/src/` Next.js app, components, lib (invoke `explore` skill).
- `plugins/` plugin services like file-manager and bank-advisor.
- `packages/` shared libraries and SDKs.
- `docs/` indexed documentation.
- `infra/` docker-compose and infra configs.
- `scripts/` operational utilities.

### Common searches (rg)
- Backend routers: `rg --files -g 'apps/backend/src/routers/*.py'`
- Backend services: `rg --files -g 'apps/backend/src/services/*.py'`
- Frontend pages/layouts: `rg --files -g 'apps/web/src/app/**/*.tsx'`
- React components: `rg --files -g 'apps/web/src/components/**/*.tsx'`
- Plugin code: `rg --files -g 'plugins/**/src/**/*.py'`

### Before you change anything
- Confirm the doc index entrypoint and read the relevant guide.
- Identify the service entrypoint(s) for the area you are touching (invoke `explore` skill).
- Check for test coverage and run minimal checks.
- Do not commit secrets or env files.

## Minimal checks
- `make test T=api`
- `make test T=web`
- Optional: `make test T=e2e`
- Preferred runner: `/quick-checks` (writes `.claude/docs/quick_checks.md`).
