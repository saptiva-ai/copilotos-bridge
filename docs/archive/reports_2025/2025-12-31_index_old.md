# Reportes de Implementación

> Documentación de resultados, análisis y estado de implementaciones.

## Convención de Nombres

**IMPORTANTE**: Todos los reportes deben seguir el formato ISO:
```
YYYY-MM-DD_descripcion-en-kebab-case.md
```

Esto permite:
- Ordenamiento cronológico automático
- Identificación clara del momento del reporte
- Evitar "context rot" (información obsoleta)

## Estructura de un Reporte

```markdown
# [Título del Reporte]

> Fecha: YYYY-MM-DD
> Autor: [nombre]
> Estado: [completado|en-progreso|archivado]

## Resumen Ejecutivo
[2-3 párrafos]

## Contexto
[Por qué se hizo este análisis]

## Hallazgos
[Resultados principales]

## Recomendaciones
[Acciones sugeridas]

## Próximos Pasos
[Si aplica]
```
