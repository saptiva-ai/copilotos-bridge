## Paso 3: Deploy de Nuevas Imágenes

### 3.1 Pull de imágenes desde Docker Hub

```bash
cd ~/octavios-chat-bajaware_invex

# Pull de todas las imágenes v1.3.0
docker pull jazielflores1998/octavios-invex-backend:1.3.0
docker pull jazielflores1998/octavios-invex-web:1.3.0
docker pull jazielflores1998/octavios-invex-file-manager:1.3.0
docker pull jazielflores1998/octavios-invex-bank-advisor:1.3.0
```

### 3.2 Actualizar docker-compose para usar nuevas imágenes

Edita `infra/docker-compose.yml` y actualiza las imágenes:

```yaml
services:
  backend:
    image: jazielflores1998/octavios-invex-backend:1.3.0
    # ... resto de la configuración

  web:
    image: jazielflores1998/octavios-invex-web:1.3.0
    # ... resto de la configuración

  file-manager:
    image: jazielflores1998/octavios-invex-file-manager:1.3.0
    # ... resto de la configuración

  bank-advisor:
    image: jazielflores1998/octavios-invex-bank-advisor:1.3.0
    # ... resto de la configuración
```

### 3.3 Hacer backup de la base de datos (CRÍTICO)

```bash
# Backup de MongoDB
docker exec octavios-chat-bajaware_invex-mongodb mongodump --out=/tmp/backup-20260106

# Copiar backup fuera del contenedor
docker cp octavios-chat-bajaware_invex-mongodb:/tmp/backup-20260106 ./backups/mongodb-20260106
```

### 3.4 Detener servicios actuales

```bash
cd ~/octavios-chat-bajaware_invex

docker compose -f infra/docker-compose.yml --env-file envs/.env down
```

### 3.5 Levantar servicios con nuevas imágenes

```bash
# Modo producción (sin volúmenes de desarrollo)
docker compose \
  -f infra/docker-compose.yml \
  -f infra/docker-compose.production.yml \
  --env-file envs/.env \
  up -d
```

### 3.6 Verificar que los servicios están healthy

```bash
# Esperar 30 segundos para que inicien
sleep 30

# Verificar estado
docker compose -f infra/docker-compose.yml ps

# Verificar logs
docker compose -f infra/docker-compose.yml logs --tail=50 web
docker compose -f infra/docker-compose.yml logs --tail=50 backend
```

## Rollback en Caso de Problemas

Si algo falla, puedes hacer rollback rápido:

```bash
cd ~/octavios-chat-bajaware_invex

# Detener servicios
docker compose -f infra/docker-compose.yml down

# Volver a versión anterior (cambiar tag)
# Editar infra/docker-compose.yml y usar tag anterior (ej: 0.1.2)

# Levantar con versión anterior
docker compose \
  -f infra/docker-compose.yml \
  -f infra/docker-compose.production.yml \
  --env-file envs/.env \
  up -d
```
